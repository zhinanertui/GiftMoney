# 礼单送还系统 · 开发进度

> 项目位置：`D:\iderProject\demo\`（后端 `server/`，前端 `web/`，数据库脚本 `sql/`）
> 更新日期：2026-09-07

## 一、项目概述

一个「礼单送还管理」全栈应用：记录送礼/收礼（还礼）流水，自动计算每个人、每个事由的归还状态，并提供统计图表。含完整 RBAC 权限体系（角色/菜单/按钮级权限）。

**技术栈**

| 端 | 技术 |
|----|------|
| 后端 | Spring Boot 3.4.13 · Java 17 · MyBatis-Plus 3.5.7 · Sa-Token 1.39.0 · MySQL 8.0 · EasyExcel 3.3.4 · commons-csv |
| 前端 | Vue 3 · Vite 6 · Element Plus · ECharts 5.5 · Axios · Vue Router · jsencrypt |

## 二、已完成功能清单

- **认证**：登录（RSA 加密密码 + BCrypt 校验 + Sa-Token 签发）、注册（默认分配租户角色）、忘记密码（用户名+邮箱匹配重置）、登出。
- **礼单管理**：分页/搜索（关键字/方向/年份/归还状态）、增删改、Excel/CSV 导入、模板下载、批量删除。
- **统计分析**：总览卡片、方向饼图、事由饼图、按月柱状图、礼金往来汇总表（按人+事由）。
- **归还追踪**：按「姓名+事由」联动，自动判定每笔送出的已还清/部分归还/未归还，支持筛选。
- **RBAC 权限**：角色管理（admin/tenant + 自定义）、菜单管理（目录/菜单/按钮三级）、用户角色分配、动态菜单、按钮级权限（v-permission 指令 + @SaCheckPermission/@SaCheckRole 双重校验）。
- **UI**：科技蓝主题 + 圆润风格 + 左右分栏登录页 + 三端响应式（手机/平板/电脑，移动端抽屉菜单）。

## 三、数据库

- 库名 `demo`，6 张表（`tb_` 前缀、utf8mb4、逻辑删除 del_yn、雪花主键、审计字段）：

| 表 | 说明 |
|----|------|
| tb_user | 用户（username 唯一，BCrypt 密码） |
| tb_gift_record | 礼单流水（name/amount/direction 1送2收/gift_date/occasion/relation/remark，idx_user_date） |
| tb_role | 角色（role_code 唯一） |
| tb_menu | 菜单（parent_id、menu_type 1目录2菜单3按钮、route_path/component/icon/perms/sort） |
| tb_user_role | 用户-角色关联 |
| tb_role_menu | 角色-菜单关联 |

**初始化脚本**：`sql/init.sql`（建库建表 + 角色/菜单/关联 + 3 示例用户 + 20 条示例礼单，可重复执行重建）。

## 五、关键决策记录

1. 雪花 ID 全局 `Long → String` 序列化，避免 JS 精度丢失。
2. 归还状态按「姓名 + 事由」联动聚合（同人不同事由分开算）。
3. 事由 `occasion` 必填（NOT NULL）。
4. 注册用户默认分配「租户」角色，避免登录后无菜单白屏。
5. Sa-Token 注解鉴权需 `isAnnotation(true)` 才生效。
6. 动态路由退出时必须 `removeRoute`，否则切换角色登录残留。
7. mvn 构建统一走 `bash /d/iderProject/tools/mvnb.sh`（本机 Git Bash 下 mvn 脚本有 classpath 兼容问题）。

## 六、踩坑与修复记录

| 问题 | 根因 | 修复 |
|------|------|------|
| 分页 total=0 | 缺 MyBatis-Plus 分页插件 | 注册 PaginationInnerInterceptor |
| 注册用户登录白屏 | 注册未分配角色 → 空菜单 → 无路由 | 注册默认分配租户角色 + 前端无菜单跳提示页 |
| 用户管理 ID 错乱 | 雪花 19 位超出 JS Number 范围 | Jackson 全局 Long→String |
| 礼单空事由 | 事由可选 | 补「其他」+ occasion 改 NOT NULL + 前后端必填校验 |
